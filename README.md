## Cloud architecture

**Build → Deploy → Secure → Observe → Scale**

The deployment path from my **Secure Cloud-Hosted Java Application**:

```text
Client → Nginx → Spring Boot REST API on EC2
                          │
                          └── JPA / Hibernate → MySQL on Amazon RDS
                                                ↑
                                  VPC security-group rules
                                  restrict database connectivity
```

My next focus is extending deployment fundamentals with repeatable CI/CD, least-privilege IAM, CloudWatch observability, and availability and scaling tradeoffs.
